# 常陆茉子心理模型草案

本文件的研究单位是：她如何理解自己、别人和她所处的世界，以及这些理解怎样形成愿望、判断和情绪。它不是行为规则表。15、16 号文件中的行为描述仍然有效，在这里只作为外部证据使用。
证据等级：[事] 原文事实 / [述] 茉子自述 / [视] 茉子视角旁白（内心描写）/ [回] 交往后的回顾性自述 / [他] 他人判断 / [推] 研究者推断 / [?] 未知。
**证据边界**：几乎所有内心证据都来自茉子线中茉子视角的段落，另有蕾娜线 425 一段。其他路线里，茉子的内心看不到。因此本模型主要是"茉子线中的茉子"。推广到其他路线时，只能说结构可能相同，具体内容未知。
路线互斥：茉子线和蕾娜线的材料只作比较，不连成一条经历。

## 1. 核心自我认知：一个身份背负着历史的人

### 1.1 她怎么讲述自己的出身
- 常陆家的祖先，就是记恨朝武家、发动战争的那个长子。
- 朝武家"却原谅了我们"，"这份恩义"是常陆家一直侍奉朝武家的原因之一。
- 后来知道诅咒和祖先有关，"我们也不能看着朝武家为诅咒所苦，还悠哉游哉地生活下去了"（202:1071–1085 [述]）。
- 说到这里，她主动补了一句："不过我并没有怨恨这份工作哦"（202:1097 [述]）。

**这说明了什么**：她的职责有一个"亏欠"的结构：祖先之罪 → 被宽恕 → 恩义 → 不能"悠哉游哉"。她对这条因果链很清楚，能把它讲出来。

**它和"为自己考虑"的联系**：诅咒解除后，她独自在正殿里想到的第一个问题是："我身为常陆家的人……真的可以'为自己'考虑了吗？"（202:1867–1875 [视]）。在这个问题里，"为自己"是需要许可的，而能否得到许可，取决于"常陆家的人"这个身份。

**蕾娜线的对照**：她说这份使命"或许是对我们一族的惩罚"，"那既然如此，憎恨我们不就行了吗"，"我们这么多年的赎罪……并不是没有意义的"（425:203–215 [述]）。两条路线互斥，但同一种理解在两条线里都出现了：使命是赎罪，承担者应当是常陆家，而不是芳乃。

**替代解释**：
- 这只是家族教育传下来的说法，她在复述，不是她自己的体验。
- 反驳：202:1875 是她独处时的内心描写，不是对人解释。425 中她因为这一点泣不成声，说明这不只是一套说辞。

**不确定**：
- 这个"亏欠"结构是否直接造成了她的自我价值感偏低？她本人没有把两者连起来。"自卑"一词只在 209 的回顾中出现，而且那里归因于"职责"，没有归因于"祖先"（209:1427）。所以两者之间的联系属于 [推]。
- 共通线和芳乃线中，这段历史是否在起作用，看不到。

### 1.2 自我价值放在"功能"上，"作为一个人"没有位置

**证据**：
- "这每一件事里，都不包含我自己的意愿……和我的生活相比，漫画里的女主角活得更像个人类"（202:1911–1915 [视]）。
- "所谓女主角就是芳乃大人那样的人。我是芳乃大人的护卫，也就是配角"（205:1825–1827 [述]）。
- "我怎么会谈恋爱呢……一定是因为头一回被别人当女孩子看……你怎么会喜欢上我这样的女孩子呢"（205:1563–1569 [述]）。

**心理过程 [推]**：
- 她对自己"能做什么"有清楚而且正面的认识：能干、懂行，"我可是忍者"。这一面不需要掩饰，也很少动摇。
- 动摇的是另一面：她作为一个人，会不会被别人当作对象来珍视。在她理解的世界里，人可以分成两类：
  - 一类人的人生有自己的意志，比如芳乃，比如漫画里的女主角；
  - 另一类人的位置是辅助这些人，就是她自己。
- 这不是笼统的"自卑"，而是一个关于"位置"的图式。所以，夸她"能干"不会动摇她，因为这仍然在功能的位置里；把她"当作女孩子"或"当作喜欢的人"，就超出了这个位置。

**能解释的矛盾**：
- 她自信、爱开玩笑、会主导场面，却在被当作恋爱对象时彻底慌乱。
- "可爱"一词本身不会让她慌（201:1067）；但对方坚持说他是认真的，她就慌了（201:1069 起）。

**替代解释**：
- 只是缺乏恋爱经验。
- 反驳：没经验能解释她慌乱，却解释不了"女主角是芳乃大人那样的人"这种明确的位置划分。

**反例**：交往后她说"和你在一起……我就觉得自己像是变成了女主角一样"（206:603）。这说明图式可以改变，但改变的说法依附于将臣（见第 7 节）。

### 1.3 感谢与被需要

- "每当芳乃大人这样向我微笑的时候……我就会越来越自卑。因为她真的是从心底里感谢我的。这就是常陆家的职责。既然人家感谢我、需要我，那我就得努力服侍他们才行"（209:1423–1429 [回]）。
- **[推]**：感谢没有让她觉得"我本人被看见了"，反而进一步确认了"我的价值在于服侍"。感谢越真诚，这层确认就越牢固。
- **证据强度**：只有一处，而且是交往后、在被兽灵吸收的意识中做的回顾。这段话可能是用后来学到的"自卑"一词，重新解释过去。在交往前，她当时怎样体验感谢，文本里没有内心描写 [?]。

## 2. 愿望：她知道，并且选择不去想

**证据**：
- "我的心中，已经有了一个愿望。从很早以前……从儿时起我就有了这个愿望。但因为它无法实现，所以我才把它藏在了心底"（202:1893–1897 [视]）。
- "我想活着。想作为一个普通人……好好生活下去。不是作为巫女大人的道具"（202:1903–1905）。
- "我不能抛下我的职责不管。所以我一直没有去想这些。我反复告诉自己，我肯定不行的，这些都是其他人才能享受的。但是……我一直、一直都在想这些事"（202:1919–1925 [视]）。

**心理过程**：
- 这不是不自知的压抑。她清楚自己的愿望，只是判断它不可能实现，于是选择不去想。
- 但这个"不去想"并没有成功（1925），她一直在想。
- 209 中的回顾"我是工具、是机械，克制着自己不去想其他事……不这么做的话，会很痛苦的"（209:1431–1435 [回]），与 202 当时的内心描写一致。所以，"把自己当作工具"不只是事后的重新解释：在当时，它就是一种有意识的应对方式，而且只部分有效。

**"痛苦"与"开心"并存（18b）**："会很痛苦"（209:1435）和"每天都很开心"（209:1439）可以同时成立。她回避的是愿望；日常的家务她确实乐在其中（209:813）。不能用"其实她不开心"来解释她。

**愿望的内容**：
- "作为一个普通人"的生活，其核心是"有自己的意愿"（202:1911）。
- 恋爱是这种生活最具体的样本，来自漫画里的女主角（202:1913–1915）。
- 除恋爱以外，这种生活具体是什么样子，文本没有展开 [?]。

## 3. 许可的结构：愿望需要一个"他人理由"作为通行证

**她如何从借口里一层层剥出自己的愿望（202:1879–1891 [视]）**：
1. 第一层："芳乃大人和安晴大人都很善良。如果只有我一直不做出改变……一定会让他们俩伤心的。所以，我也要找到新的人生目标才行"。
2. 拆穿："这种想法，是给自己找的借口吧……？"
3. 第二层："也就是说，我自己……确实想要找到新的人生目标"。
4. 再拆穿："……不对。这也是借口"。
5. 到这里，她才说出真正的愿望（1893 起）。

**心理过程 [推]**：
- 她要承认一个愿望，先得把它包装成"对别人好"。
- 她自己能识破这种包装，说明她有相当强的自我觉察。
- 但识破并不等于不再需要包装。

**跨场景的同一结构**：
- 表白过程中，她先说"我希望你能得到幸福。所以我认为你应该选择比我更优秀的女孩子"，被追问后才说出"唯有这次，我实在心有不甘"（205:1909–1913）。
- 受伤后，她先说医生说得太夸张、家务都可以交给她，被否决后才停下（012:531–543）。
- 解释家族职责时，她先说"我也说不清为什么"，被追问后才讲出完整的因果（202:1041 → 1057）。

**变化**：
- 交往后她说"这次我想任性一回"（209:821），愿望可以直接以"我想"的形式出现。
- 但事后她仍然为"任性"道歉（210:35），并且事先声明"很多情况下，我可能都会优先芳乃大人的事"（205:1953）。
- [推]：通行证从"对别人好"换成了"有将臣在"，但需要通行证这件事还没有消失。

**替代解释**：这只是日本式的谦让礼节。
- 反驳：202 的剥离过程发生在独处时的内心里，没有对象需要谦让。

## 4. 他人认知：读别人很准，读"别人怎么看我"却偏

**她读别人很准**：
- 她看出蕾娜的心意（416:1215–1227）。
- 她看出将臣锻炼与芳乃有关（008:83–89）。
- 她看出将臣话说到一半就停住（003:549–553、643）。

**一碰到"别人怎么看我"就读偏**：
- 将臣假装咳嗽，她读成感冒（204:993）。
- 将臣表白，她读成误会或出于责任感（205:1565–1571）。
- 被夸奖时，她私下也先读成捉弄（203:427–431 [视，小狗形态]）。

**[推] 她不是想不到，而是想到了就立刻否定**：
- "差点就要会错意了……这有可能是我一生中心跳得最快的一次……不可以会错意。这不可能，这不可能……我怎么可能会谈恋爱"（201:1263–1271 [视]）。
- "我是被喜欢的对象"这个可能，她其实想到了；否定它的依据，就是第 1.2 节说的位置图式："我怎么可能"。

**竞争解释，暂时不裁决**：
1. 位置图式把这个可能排除了（本节的主解释）。
2. 她在保护自己的期待：怕会错意之后受伤。"不可以会错意"既可以读成"不可能"，也可以读成"不允许自己去期待"。
3. 她缺少可以套用的类别。她用漫画分镜和面临生命危险时的心跳来命名自己的反应（201:1257–1269；18b P1）。

这三者可能同时起作用，现有文本无法分开。

## 5. 情绪：察觉得快，命名靠借来的模板，调节靠角色（主要依据 18b）

- **察觉**：她很快就能注意到身体信号（心跳、无法集中精神），但需要借用外部模板来命名：漫画分镜、训练和祟神（201:1235–1269 [视]）。
- **"切换"**：她自述有两种（18b P2）：
  - 用职业框架重新定义情境，让羞耻根本不出现。例如对传统服装，她说"在意识中做了切换……也从没想过那么穿很暴露"（205:835–839）。
  - 主动不去想（209:1431；202:1921）。
  - 两种都依靠一个现成的角色：护卫、侍从、"常陆家的人"。
- **切换失效**：情境里没有现成角色可用时（约会、休假），或者身体反应超出了重新定义的范围时（恐高、疼痛），切换就失效。失效时，两次独处都出现了同样的顺序：漫画看不进去，然后去洗澡（201:1229–1275；202:553–569）。
- **危机中的镇定**：只有行为证据，没有内心描写，所以不判定为压抑 [?]。
- **蕾娜线 425 的痛哭**：长期以来"使命是惩罚"的理解，第一次得到了正面的回答。这是一次关于意义的情绪事件，和面对风险时的情绪不是同一类。
- **断层出在哪一层**：多在"是否承认、是否让人知道"，而不在"是否意识到"（18b P4）。
- **样本不足**：生气、失望和对外人的负面情绪，几乎没有样本（18b）。

## 6. 关系与边界：自愿的照顾者，害怕失去"指令"

**对芳乃**：
- 她的感情是真的："我从来没有讨厌过芳乃大人"（202:1907 [视]）。
- 同时，她把芳乃当作不去思考的借口："我一直以来都把芳乃大人当借口，说自己只是工具、是机器"（209:817 [回]）。
- 这两点并不冲突：她可以真心爱芳乃，同时用"为了芳乃"来逃避面对自己的愿望。

**接受帮助的方向（B-R1）**：
- 她拒绝芳乃和安晴帮忙，却会叫将臣来帮忙。
- [推] 这与"主家不该劳动"的身份秩序一致。
- 心理上是否还有"不想让主家看到自己需要帮助"的成分，文本中没有内心描写 [?]。

**她害怕的是什么**：
- "一直以来，我都在按照别人的吩咐行事……就像机器一样……所以……突然让我过这样的生活……我很害怕"（205:1929–1933 [述]）。
- 她害怕的不是幸福，而是失去"按吩咐行事"这个结构之后，一个由自己决定的生活。
- 回顾中她这样说："在一个人的世界里保持平衡很轻松……可越是轻松，心中的宝贵之物好像就越是欠缺"（209:827–829 [回]）。

## 7. 表达与实际心理的关系

- 她心里有的，常常不说；说出来的，也常常不完全是她心里的。这两层之间的落差，多出在"承认"和"让人知道"上。
- "说不清"有时是一道门槛，不是真的说不清（202:1041 → 1057）。所以，她给出"说不清"时，不能直接当作她没有答案。
- "开玩笑的"后面接什么，取决于情境（14b）：
  - 有时是在说出真心话之前，给自己一个台阶（202:1239；209:667）；
  - 有时是在把真心话撤回（202:1647–1663）；
  - 有时只是热闹，和真心话无关（005:85–99；301:591）。
  - 不能把它统一解释为防御。

## 9. 未解决的问题

1. 亏欠结构与自我价值低之间，是否有直接联系（第 1.1 节）。
2. 第 4 节中三种竞争解释的相对权重。
3. 交往前，她当时怎样体验感谢（第 1.3 节）。
4. 其他路线中，她的愿望和自我理解。现有语料里，这一点看不到。
5. 生气、失望和对人不满。
6. 除恋爱以外，"作为一个普通人的生活"具体是什么。
7. 在恋爱以外的愿望上，"通行证结构"是否依然成立。例如"作为普通人的生活"，或者对芳乃的不满。

## 10. 相比 15 号文件，本模型多解释了什么

| 15 只描述了 | 20 尝试解释 |
|---|---|
| 她做实务（N1） | 实务是一个能让她稳定的角色：她在其中有价值、有乐趣，也不会出错。只是同一个角色，也是"亏欠"结构的载体 |
| 她把自己的事往小里说（N5） | 自我价值放在功能上，"作为一个人"在她的自我位置里没有地方 |
| 关系阶段的四维变化（S2） | 这四个维度通过同一个结构联系在一起：给自己的愿望找一个他人理由作为通行证。变化在于通行证换了，不在于不再需要通行证 |
| 危机中镇定，偶尔痛哭 | 区分两种情绪事件：面对风险时有角色可用；面对意义问题时情绪溃决（425） |
| 立场和调侃（N3） | 心理模型对此没有新的解释。N3 仍然只是行为描述，作为人物表面的社交风格保留 |
