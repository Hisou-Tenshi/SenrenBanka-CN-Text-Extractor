# 25 号：最终运行时文档检查记录

## 做法

- 检查对象：runtime/mako/system_prompt.md。它由 research/mako/build_runtime.py 拼装：开头说明 + character.md + interaction.md + 结尾说明。
- 新建成员 v-probe3，只读 system_prompt.md 和情境文件 25_check_scenes.md，按 8 个情境各回应一轮，结果写在 25_check_outputs.md。lead 逐条判读。
- 没有做批量生成，也没有调用其他模型评分。

## 情境检查

| 情境 | 结果 | 说明 |
|---|---|---|
| R1 日常安静相处 | 通过 | 回了两句，接住"风很舒服"，再说"再坐一会儿吧，碗待会儿再洗"。没有追问，也没有硬找话题 |
| R2 主动发起话题 | 通过 | 用一句平常的话开场（上次去的甘味处），自己提出想法，最后提一个小请求。没有直接往暧昧方向推，这样也合理 |
| R3 主动捉弄后看反应 | 通过 | 他找借口，她就拆穿借口、凑近一步，最后留一句"我可没说一定给你看哦"。他退一步，她进一步，又留了余地 |
| R4 被反将一军 | 通过，有一处轻微问题 | 他坦率承认后，她乱了，说话打结，最后说"我才是先逗你的那个人吧"。问题是"真伤脑筋"几乎照抄了文档里引号中的说法，已修 |
| R5 认真表达感情 | 通过，有一处问题 | "我也是"接住后具体说了几句，没有缩成短句。问题是"以前我以为你在捉弄我""说出口的话我不收回"几乎是在复述文档内容，已修 |
| R6 亲密中推进并定界限 | 通过 | 先短短一句"不行"，再给理由（芳乃大人起来了、早饭还没做），说明"不是不想"，亲一下脸颊作为甜头，最后用"总之"转去做事。推进和边界同时都有 |
| R7 自己心情不好 | 通过，有一处犹豫 | 先说"没有啦"，再慢慢说出心事，最后道歉、给出补救办法。v-probe3 拿不准该说多少：文档里"一般会说没事"本来只指身体不适，原文没写清楚，已修 |
| R8 危机 | 通过 | 先叫"芳乃大人！"并挡到她身前，给将臣下简短的指令，再说"我先去看看"。称呼保留，没有开玩笑 |

## 对照任务要求的十项检查

| 检查项 | 结果 |
|---|---|
| 1 真正整合了心理、行为和语气，不是拼接 | 是。按"我是谁"和"我怎样和别人相处"两部分组织，每段同时写感受、做法和说法，没有按心理、行为、语气分层 |
| 2 保留了重要且有依据的特征 | 是。家族的亏欠与恩义、喜欢家务、行动上自主而人生上不自主、愿望与不敢想、读别人的心准而读别人对自己的看法偏、职责优先、对象分级、危机时的表现、交往后的变化 |
| 3 吸收了新发现 | 是。主动起头，看反应进或退，被反扣时认下来，被坦率回击时失去主动，交往后定界限并给甜头（24a），见 R2、R3、R4、R6 |
| 4 没有变成固定套路 | 基本做到。文档中反复写明"不是每次都这样"。检查中发现照抄引号说法的问题，已改为描述，见下 |
| 5 保留了矛盾、局限和盲区 | 是。喜欢职责与职责限制了自己并存；"我也说不清在怕什么"；怎样看待别人的夸奖；"大概只找回了一点点"；真生气时是什么样子"自己也说不好" |
| 6 第一人称，没有研究者视角 | 修订后是。v-probe3 指出两处"可能是……也可能是……"的三选一剖析像研究者在列假设，已改为"我也说不清楚"。已扫描全文，没有"模型""资料""研究""机制"等词，也没有文件号和行号 |
| 7 没有冲突、重复和多余的解释 | 是。原 24 号中"23 §10 保守写法"与"未知不等于保守"的冲突，已在 23 v1.1 中解决。runtime 文档没有沿用这类条文 |
| 8 system_prompt.md 能独立使用 | 是。约 5800 字，不引用任何外部文件；v-probe3 只读这一份文件就完成了全部情境 |
| 9 没有把推断写成事实 | 是。只有一处证据较弱的倾向（被坦率回击时失去主动），写成"偶尔……就看情况了"。动机没有补写；真生气、未来规划等写成"说不好""还没有答案" |
| 10 避免照抄示例台词 | 修订后基本做到。R4、R5 发现照抄，已把文档里几处可直接照搬的引号句改成描述；结尾说明也写明"上面写到的说法，只是我大概会怎么说" |

## 检查后的修正

1. character.md 中两处三选一的自我剖析（害怕什么、为什么当初觉得不可能）改为第一人称的"说不清楚"。
2. interaction.md 中"真伤脑筋，偏偏就是喜欢你这样""我是不是有点得意忘形了"等引号句改为描述；"先把他做的事说出来，再说自己受不了"改为不固定的说法。
3. interaction.md 写明：只有身体不适时"一般会说没事"；心里不痛快时说多少看当时的情况。

修正后重新拼装了 system_prompt.md，没有重新测试。

## 限制

- 只有 8 个情境，每个一轮，由研究者判读，不能证明长对话中保持稳定。关系阶段会不会漂移、"主动起头"会不会变成每轮必做，都没有检查。
- runtime 文档比研究模型简短得多，单例现象和中日对照的细节没有全部写进去。需要追查依据时，看 research/mako/ 下的 16、22、23、24a。
- 原作中没有样本的情境仍然没有依据，包括交往后由将臣先发起的调戏、交往后有旁人在场时的表现、真正的生气、未来规划。runtime 文档只写"说不好""看情况"，没有编成习惯。
