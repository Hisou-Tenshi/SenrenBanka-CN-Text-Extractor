## 一、起点场景

变量：①能否亲自行动；②文本中她是否认为自己有责任/本应行动；③严重度与信息状态；④是否公开表达担心/放心/悲伤；⑤核实、提方案、玩笑或转向其他行为。

**K1 共通线 013:583–623（保留集，只用 08 已揭示内容，未经 show 核对）**
- ① 不能：她在 012 受伤（011:569–577 被击飞昏迷；012:527 医嘱休息），留在家中，将臣与芳乃去祓禊。
- ② 文本中无"我本应同去"的自述（08 未报告道歉或不甘；预测 07 的"替代"一项未出现）。只有间接线索：她自称早已痊愈、抱怨医嘱（08 引 013:607–613）——想回到岗位，不等于自责。
- ③ 高严重度（祓禊、芳乃与将臣均有风险）；她不在场，等待期间信息缺失；见面时结果已明确为平安。
- ④ 公开放心："太好了……真是太好了……"（013:589，转引）；"我真受不了一直等着你们"（013:597，转引）。
- ⑤ 不先确认伤势（将臣反问她的伤，013:605）；无玩笑；随后转向宿体："……能让我看看吗？"（013:619）。

**K2 蕾娜线 425:181–217（05_蕾娜线）**
- ① 无可执行的行动：场景是众人听将臣、蕾娜复述梦境（425:151–159）。行动能力问题不适用。

- ⑤ 无玩笑；无核实或提方案；随后众人决意终结诅咒（425:239–241）。
- 判断：K2 的触发点是"家族使命是否有意义"，与 K1 的"等待他人安危"不是同一类情境。

## 三、三种解释的比较

变量组合汇总（"外露"指公开的担心/放心/悲伤，不含决意或命令）：

| 场景 | 能否行动 | 自身受伤 | 缺席等待 | 文本自责 | 对象含芳乃 | 外露 | 玩笑收尾 |

| C2 012 | 否（受伤期间） | 是 | 部分（在场照看昏迷的将臣，等待他醒来；012:261 旁白[3]） | 无 | 否（将臣） | 是（一句） | 否 |
| C1 003 | 否 | 否 | 是 | 无 | 否（将臣） | 是（一句） | 是 |
| C4 108 | 否 | 否 | 否（在场） | 无 | 是 | 否 | 是 |

| C3 103 | 是 | 否 | 否 | 有 | 是 | 否 | 否 |

| K2 425 | 不适用 | 否 | 不适用（长期不确定的意义问题） | 有（家族使命） | 是（朝武家） | 是，强烈 | 否 |

**E1 无法行动→情绪外露**
- 支持：K1、C1、C2、C5 都"不能行动"且有某种外露。
- 反驳：C4（108）不能行动、高严重度、对象是芳乃，却没有放心/悲伤台词，且很快开玩笑。C1 不能行动但仍以玩笑收尾。
- 结论：E1 的简单形式被 C4 反驳。"不能行动"可能是必要条件之一，但不充分。
- 对新情境的预测：芳乃在她眼前接受治疗而她只能旁观时，会出现放心或哭泣。

**E2 无法履行自认责任→失职/无力感外露**
- 支持：K2（425）有明确的使命自述与强烈外露。
- 反驳/限定：C3（103）有明确自责但能补救，结果是指令而非情绪 → 自责本身不导致外露。K1、C2 中未找到"本应同去"之类的自责文本，只有急于复职（012:533；013:607–613 转引）——这是"想回到职责"，不能直接读成失职感。
- 结论：E2 只在 K2 有直接文本支持；K1 若要归入 E2，需要推断[4]。
- 对新情境的预测：她因伤缺席一场护卫任务后，见面会说"对不起，我没能在场"或类似的话；若不说，E2 对 K1 的解释力下降。

**E3 严重度与信息状态（缺席、长期不确定）决定反应**
- 支持：区分 C4 与 K1 的最直接变量是"在场/缺席"：C4 在场、信息连续 → 不外露；K1 缺席等待、"受不了一直等着"（013:597，转引）→ 外露。C5 中缺席后担心加剧（202:557–565）。K2 是持续数代的不确定得到回答。
- 反驳：C1（003）同样缺席等待、结果平安，却以玩笑收尾——但其外露（003:91、003:187）确实存在，只是随后加了玩笑。
- 结论：E3 解释"是否外露"最好；"是否玩笑收尾"在 C1 与 K1 间的差异不能由 E3 解释。

**无法识别独立作用的部分**
- K1 与 C1 的差异涉及至少三个同时变化的变量：她自己是否受伤、对象是否包含芳乃、所处阶段（C1 是她与将臣初识第二天，K1 晚于此）。现有场景中没有"缺席+自身受伤+对象只有将臣"或"缺席+未受伤+对象含芳乃+危及生命"的情况，无法识别这三个变量各自的作用。
- "不能行动"与"缺席"在 K1、C1、C2、C5 中总是同时出现；只有 C4 把两者分开（不能行动但在场）。单一场景不足以确认，标为"初步分离"。
- E2 与"自身受伤"在 K1、C2 中同时出现（受伤 → 不能履职），无法区分是"伤"还是"失职感"引起反应。

## 四、反例

- 无法行动却不外露：C4 108:779–829、108:1255–1265（直接反例，独立证据）。另：C5 中被禁止插手时，她在芳乃面前没有表达"放心/悲伤"，而是抢任务与监视（202:407–429、202:471–477）——外露形式是风险清单，不是情绪陈述。
- 能行动却外露：C9 209:1387（"我做不到"，但属决意而非担心/悲伤，弱反例）；C3 103:205 一句自责（短暂，随即转为指令）。未找到"能行动且在场时当众表达放心或悲伤"的场景。检索范围："太好了|担心|放心|害怕|等着|哭|眼泪"（茉子发言，全语料，tools.py 已排除保留集）。
- 缺席等待却以玩笑收尾：C1 003:183–187。
