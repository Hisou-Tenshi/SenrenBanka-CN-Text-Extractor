路线：共=共通线，芳=芳乃线，茉=茉子线，丛=丛雨线，蕾=蕾娜线。置信度：高 / 中高 / 中 / 中低 / 低。

## 0. 结构

v1 有六条并列规律。v2 把它们改写为四个核心机制，外加一组条件。每个机制按"注意 → 理解 → 顾虑 → 行动 → 表达"来写，最后给出可检验的预测钩子。

| v2 | 吸收的 v1 / 候选 | 变动 |
|---|---|---|
| K1 照看者的默认姿态 | M1、M6、C-R2、C-R3、"活动以照顾为名" | 合并；"不提议出去玩"改写 |
| K2 风险按归属与在场处理 | M2、A-R2、A-R3、09a | 加入"在场与否"；"危机后用玩笑"降级 |
| K3 按对象分层的互动语域 | M3、B-R5、09b 护面子边界 | 护面子的界线改为"明确制止" |
| K4 信息归属：别人的隐情不替人说，看得见的就点明，自己的往小里说 | M4、M5、09b、09c | M4 与 M5 合并，按信息类型重写 |
| 条件 C1–C4 | 关系阶段、路线、喜剧场面、长辈在场 | 新增 |

## 1. 核心机制

### K1 照看者的默认姿态（置信度：中高）

- 注意：吃饭、洗澡、日程、换衣服这类时间节点；谁累了、谁受了伤、谁还没吃饭。
- 理解：这些事默认由她负责。
- 顾虑：别让主家劳累；别打乱大家的安排。
- 行动：
  - 宣布下一步该做的实务，例如"我马上上早饭"（111:275）、"那我去做点夜宵"（108:1265）。
  - 拒绝芳乃、安晴帮忙，转而让将臣来帮（303:37–81）。
  - 自己受伤时淡化伤情，直到医生或芳乃否决才停下（012:529–553）。
  - 给人添了麻烦后，用晚饭、洗澡水等劳务补偿（C-R3，只见于共通线）。
- 表达："我可是忍者"用来解释自己的能力和体能，不用来掩饰弱点（103:115–121；010:1783–1815 是自信过度后失败）。
- 发起活动：她发起的活动，多以照顾、报答或职责为名（302:423–433；003:553；006:419）。目前没有找到她纯为自己娱乐而发起活动的例子（中）。
- 收到邀约：先提一个顾虑，被放行后才接受（010:183；207:303–339）（中高）。
- 反例与边界：
  - 将臣受伤时，她连将臣帮忙也不接受（003:621–623）。
  - 芳乃下命令时她会服从（202:341–453）。
- 失效情境：没有任何实务可做的纯闲聊；她是客人的场合（未检验）。
- 预测钩子：场景里出现时间节点或有人不适时，她会主动说出下一步实务。这在 P3 中多次自动出现（111:275、310:113–115、013:783 附近）。

### K2 风险按归属与在场处理（置信度：结构中高，各分支中）

- 注意：谁有危险、危险由谁承担、她自己在不在场。
- 分支：
  - 自己能控制的风险：直接去做，不商量、不解释，事后道歉但不收回判断（014:1085–1109、1245–1247）。
  - 别人自愿承担的风险：提一次代价，然后支持，转去做自己能做的部分（311:1047–1089）。
  - 弱势第三方：直接否决不安全的方案，并给出替代（414:281–311）。
  - 芳乃有风险：列出具体风险，把任务抢回来；被禁止插手，就躲起来看（202:405–477）。
  - 在场的危机：只说短命令，不开玩笑（003:1297；209:1367–1391）。可以出现"我做不到"式的决意话语（209:1387）。
  - 不在场、等待结果：再见面时先表达放心（003:91；013:589，后者为 P3 已知证据），之后会不会开玩笑不确定（003 开了，013 没开）（中低）。
- 降级：
  - 危机过后用一句玩笑回到日常：只在她在场的危机中出现（108:1255–1265），中低。
  - 不确定时先说最坏的可能：P3 中 013 窗口没有出现，中低。
  - "不能行动就让情绪外露"：被 108:779–829 反驳，不纳入。
- 失效情境：长期的意义或使命问题（425:181–217，当众痛哭），属于 K2 以外的领域，见第 3 节未知项。

### K3 按对象分层的互动语域（置信度：中高）

- 同辈（将臣、廉太郎、蕾娜、丛雨等）：
  - 调侃过程：抓住一句话或一个表情，夸张推演，看对方反应，然后收尾或借机让对方接受她的安排（006:479–507；200:107–131）。
  - 被认真反击：先反咬"你也……"；对方一直认真，她就放弃玩笑（202:1479–1485；205:1459–1475）。
  - 群体娱乐：会积极参与、带动竞争，例如"我可是不会手下留情的"（420:273–303，P3 已知证据）。她当组织者只有两例，都在蕾娜线，都有一个需要人带的新人（416:541–563）（中低）。
- 芳乃：
  - 会调侃芳乃的亲密行为，芳乃只是害羞时她还会加码（110:337–345）。
  - 芳乃明确制止，她立刻停下并道歉（101:399–405）。
  - 心事类的事，她用提问引导芳乃自己说出来（007:613–637）。
- 长辈和外人（玄十郎、店主等）：只有礼貌和顺从，不开玩笑（301:331–401；003:557–611）（中，样本少）。
- 竞争解释：
  - 调侃是不是"为了带动安排"，还是她本来就爱开玩笑，两者的预测差别小，暂不区分。
  - 安晴在场时她是否收敛（111:781–789、112:43，2 例），待验证。

### K4 信息归属（置信度：中）

- 别人没说出口的心意：从细节推断出来，但不替当事人说破。将臣问起时，让他去问本人（416:1215–1231；102:613）。
  - 例外：有第三方在场时，她会替芳乃说出芳乃没明说的心情，被芳乃制止就道歉（102:571–583；301:373–377；421:363–393）。
- 看得见的亲密行为或窘态：任何关系阶段都当面点明，然后让位，例如"电灯泡""你们继续吧"（418:271–289；108:1255–1259；308:781–799）。
- 别人已经打开的恋爱话题：积极参与。对方比她有经验时，她追问（105:413–517；111:399 为 P3 已知证据）；对方比她更不懂时，她反过来当讲解的人（110:529–575；201:353–387）。她自己发起、确实在打听信息的只有 2 例，都与芳乃有关（110:1017–1037；201:881）。
- 自己的事：
  - 往小里说："纯当爱好""也不知道算不算喜欢"（105:575；202:1251）。
  - 动机给职责类理由（003:641–663）。
  - 真心话说出口后，马上用"开玩笑的"撤回，常常再补一句小一点的真话（202:1239、1351–1359；209:667）。
  - 谈自己的恋爱，一贯说没有经验、知识来自书和漫画（中高，跨四条线）。
- 失效情境：她自己的恋情（茉子线，见 C1）。

## 2. 条件

- C1 关系阶段（只在茉子线）：
  - 表白前，将臣坚持认真夸她时，她会窘迫，把话归为捉弄，并且回避（201:1065–1123；205:943–961）。
  - 表白过程中，回避的理由从"被捉弄"变为"我配不上""怕自主生活"（205:1459–1933）。
  - 交往后，她接受夸奖，只剩难为情（207:353–377）；"捧杀"变成两人之间的玩笑（206:635）。
  - 职责优先和为"任性"道歉，在交往后仍然存在（205:1953；210:35）。
- C2 路线：
  - 将臣不是恋爱对象时，她对将臣是战友式的亲近：揶揄后马上肯定，"喜欢"限定为战友（415:513–519；302:385–391）。
  - 家族使命带来的重负，在茉子线和蕾娜线中都出现，但内容不同（D3，没有研究，不合并）。
- C3 喜剧场面：在明显的搞笑段落里，她会配合喜剧效果，例如喊叫、夸张反应（203 小狗段）。这时 K1–K4 的预测力下降。
- C4 长辈在场：可能抑制她的调侃，待验证。

## 4. 预测时的使用顺序

1. 先判断场景是否属于明显的喜剧段（C3）。如果是，降低所有预测的置信度。
2. 检查场景里有没有实务时间节点或有人不适（K1）。有的话，K1 的预测最稳。
3. 有风险时，按 K2 判断风险归谁、她在不在场。
4. 按对象选语域（K3），按信息类型决定说不说（K4）。
5. 茉子线中涉及她自己的恋情时，套用 C1。
