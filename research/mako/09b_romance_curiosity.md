## 3. 111-2b 失败的竞争解释

需要的对照：芳乃不愿意分享时，她怎么做。

| 芳乃的状态 | 场景 | 茉子的做法 |
|---|---|---|
| 明确制止（"你别……！"） | 101:401–405 | 立刻停下并道歉（1） |
| 指出她在起哄（"你是不是在瞎起哄？"） | 105:341–345 | 否认，转为正经建议（1） |
| 说她"像在看热闹" | 201:291–297 | 否认，改给职责理由，但继续问（1） |
| 只是害羞、抗议，没有要求停（"为什么你会知道""～～～！！"） | 110:339–343、429–433 | 不收，继续补充细节（1） |
| 自愿分享 | 111:411–431（转引） | 跟着追问（1，转引） |

研究者推断（4）：
- 现有材料里，"芳乃明确制止"只出现在调侃或泄露的场合（101），没有出现在她自己想知道的场合。所以"好奇压过护面子"这一点没有直接检验：没有一个场景是她很想知道，而芳乃明确拒绝。
- 只看现有材料，"芳乃自愿分享，所以不需要护面子"足以解释 111-2b。另外，"护面子"边界的实际触发条件，比 M3 写的要窄：触发的是芳乃明确制止，而不是芳乃害羞。110 中芳乃已经很窘，她却继续加码（E6），这一点 M3 的边界本身就预测不到，与 111 是否自愿无关。
- 因此，111-2b 的失败更像是 M3 边界的适用条件写宽了（把"害羞"当作"不愿意"），不需要假设好奇心压过了一切。
- 仍然无法排除"好奇压过护面子"，因为缺少关键对照（5）。

## 4. 仍成立的竞争解释与新情境预测

### 4.1 统计（研究者推断，基于 E1–E18）
- 求知型的②和③：E1、E2、E5、E9、E13，大部分出现在别人已经开启的话题里，而且常有第三人一起问（蕾娜：E1、E5；芦花自愿讲：E5）。
- ①（她主动发起）：E3、E8、E11、E12、E18。其中求知成分明确的只有 E8（问丛雨芳乃的初夜安排）和 E11（问将臣有没有喜欢的人）；E3、E18 是点破或推动；E12 是为了躲开谈自己而转问对方。E8 和 E11 都附有"为芳乃"的语境（E8 的"但愿如此"；E11 中她自己说担心两人的幸福）。
- ④（谈自己）：E4、E6、E10、E12、E13、E16 一致：没有经验，知识来自书或漫画，压低分量或限定为战友。跨共通线、芳乃线、茉子线、丛雨线，稳定（1＋2）。
- 自述的兴趣来源：006:681"那都是别人的恋爱啊"、202:1341"只是喜欢看情侣之间那种砰然心动的感觉"、201:393"恋爱这种事，我还想找人请教呢"（2）。三条都出自非独立场景。
- 反例：E16、E17、E18：有机会打听，她却只调侃、点到为止或限定立场。

### 4.2 结论性表述（研究者推断，置信度中）
"对别人的恋爱有稳定的兴趣"（爱看、爱点破、爱打听）比"对恋爱知识有稳定好奇心"更符合材料。"求知者"的姿态是有条件的：
- 话题已经打开；
- 有比她更有经验、并且愿意说的人（芦花、交往后的芳乃、安晴）；
- 常常有同伴一起问。
反过来，对方比她更不懂时，她是讲授者（E7、E10），不是求知者。08 中 F2 写的"作为求知者的好奇"，只覆盖了前一种条件。

### 4.3 仍成立的竞争解释及其对新情境的不同预测

| 竞争解释 | 新情境 | 预测 |
|---|---|---|
| A 稳定好奇（H1） | 没人提恋爱、她与有经验者单独相处（例如和美津叶、芦花闲谈） | 她会自己把话题引到对方的恋爱经历上 |
| B 参与已开放话题（H2） | 同上 | 她不会主动提；对方一提，她马上追问 |
| A | 当事人不愿说，但不是芳乃（例如芦花岔开话题，105:437 那一类） | 她会继续追问 |
| B | 同上 | 她会顺着对方收住；105:437–441 芦花自己收回话题时，茉子没有追问（1，但她当时也没说话，属弱证据） |
| C 对他人恋爱的兴趣主要服务于芳乃（E8、E9、E11 的理由） | 和芳乃无关的他人恋爱（丛雨线、蕾娜线的情侣） | C 预测她只调侃、推动，不求知（E17、E18 符合）；A 预测她照样追问 |
| D 是叙事功能（芳乃线需要有人带出性知识的喜剧桥段） | 任何情境 | 不可检验，和 A/B 的区分无关；注意 E7、E1 都处在喜剧桥段里 |

关于护芳乃面子：
- 解释 P1（好奇压过护面子）：芳乃明确拒绝说，但话题是她想知道的 → 她继续问，或者换个方式问。
- 解释 P2（只在明确制止时收手）：同样情境 → 她立刻道歉、停下（101:401–405 模式）。
- 解释 P3（芳乃害羞也会触发护面子，M3 原写法）：已被 E6 反驳，不再作为候选。
